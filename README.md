# Campus Navigation

Campus Navigation is a web-based application designed to help students and visitors easily navigate through the college campus.

## Features

- Campus map navigation
- Easy-to-use interface
- Login page
- Dashboard
- Interactive map
- Quick access to campus locations

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
